    Actions

    L'action porte sur l'objet sélectionné de l'inventaire. Pour prendre, cliquez l'objet dans la pièce. Déplacement ZQSD ou flèches, regard à la souris. Télécommande des portes : Espace. Sauvegarde rapide F5, chargement F9.

    Fichier

    F5 : sauvegarde rapide · F9 : chargement rapide. Les emplacements restent dans ce navigateur ; exportez un fichier pour changer d'appareil ou garder une copie.

    Commandes

    Z Q S D / flèchesAvancer, pas de côté, reculer. Les flèches gauche/droite tournent.
    Souris (glisser)Tourner et lever ou baisser les yeux. Molette : regard vertical.
    1 … 0Actions : Poser, Prendre, Utiliser, Appuyer, Régler, Verser, Relief, Dormir, Manger, Boire.
    [ ] ou TabChanger l'objet sélectionné dans l'inventaire.
    T / UPrendre / Utiliser.
    Glisser un objetDe l'inventaire vers la pièce (ou la vue 3D) : le poser. De la pièce vers l'inventaire : le prendre. À la souris comme au doigt.
    Espace · OTélécommande : ouvre les portes télécommandées en vue (il faut l'avoir dans l'inventaire). Manette : LB.
    EntréeRefaire l'action en surbrillance.
    ÉpilogueEn fin de partie le jeu donne un code : le bouton « Lancer l'épilogue » le tape pour vous. Depuis l'accueil, le bouton Épilogue permet de saisir un code à la main.
    F5 · F9Sauvegarde rapide · chargement rapide. Bouton Partie : 4 emplacements, export et import de fichier.
    M · V · CPlan · fil de fer ou faces · écran d'origine.
    ÉchapAnnuler un choix d'objet, fermer.
    TactileJoystick à gauche pour marcher, glisser ailleurs sur la vue pour regarder.
    ManetteStick gauche : marcher. Stick droit : regarder. Croix + A : menus d'origine. X : prendre. LB : télécommande. Y : plan. Select : vue. B : annuler.

    Pour appuyer sur un bouton ou utiliser une serrure, approchez-vous et regardez-la avant de choisir l'action, comme dans le jeu d'origine. Les codes et terminaux affichent l'écran du CPC : tapez au clavier ou sur les touches à l'écran.

    Loriciels · Amstrad CPC · 1987

    ReliefAction

    Vous vous réveillez seul dans la chambre d'hibernation d'un vaisseau à la dérive. Quelque chose rôde dans les coursives. Le jeu d'origine tourne ici tel quel, sur un Amstrad émulé ; seuls l'image, les messages et les commandes ont été modernisés.

    Sur un vrai Amstrad CPC

    La disquette du jeu a aussi été enrichie. Son menu de lancement ajoute :

    • Une traduction anglaise complète : messages du jeu, verbes, épilogue et démo. La langue se choisit au lancement (touche L), le français reste la version d'origine.
    • Un trainer : temps infini (pas d'autodestruction du vaisseau) et monstre endormi, chacun activable dans le menu.
    • Un correctif qui permet de sauvegarder sa partie avec une Multiface ou un instantané d'émulateur.
    • La démo et l'épilogue restent accessibles depuis le même menu.
